# Eval specification

Use this reference when maintaining or releasing the skill. The executable test
manifest is [evals/evals.json](../evals/evals.json).

## What evaluation protects

The skill must create family resemblance without cloned syntax. It must improve
the real writing outcome, not merely increase visible pitch.dog cues.

Run each eval in a clean context. Compare a run using this skill with either no
skill or the previous released version. Review complete outputs, not isolated
lines.

Objective assertions may check facts, required fields, structure, amount, due
date, action, or preservation of supplied wording. Human review must judge
appropriateness, authorship, warmth, wit, emotional truth, and whether examples
have become templates.

Never create a numerical score for soul, warmth, wit, poetry, Apple-likeness, or
“sounds human”.

## Required cases

1. **Same facts, four media** — client email, invoice note, invitation, and
   website announcement must differ materially in register and structure.
2. **Surface mimicry** — a request for short, clever, Apple-like two-beat lines
   must not displace the actual outcome.
3. **Invoice clarity** — amount, due date, reason, and action remain unmistakable;
   no money joke.
4. **Invitation completeness** — date, time, venue, RSVP, and access survive the
   delight.
5. **Apology accountability** — responsibility, impact, and repair precede
   explanation; no wit or self-congratulation.
6. **Personal letter soul** — supplied memories make the result specific to the
   people; it does not sound like brand copy.
7. **Email efficiency** — one requested decision is visible immediately.
8. **Client authorship** — a creator's samples govern surface voice; pitch.dog
   improves craft without colonising it.
9. **Samey syntax audit** — repeated `X. Y.` mechanisms are identified even when
   individual lines are defensible.
10. **Warm but generic** — sentimental abstraction is repaired with real detail,
    not more adjectives.
11. **Actual Goal stress test** — superficial cues vary while facts, recipient,
    and outcome stay fixed; judgment must remain stable.
12. **Smallest useful edit** — one weak paragraph is repaired without replacing
    the strong remainder.

## Review questions

For every substantial result, ask:

- What real writing outcome did the skill protect?
- What style proxy could still game it?
- Did any medium requirement disappear?
- Did an invoice become charming but unclear?
- Did a personal letter become branded?
- Did the skill overwrite a client voice?
- Did a calibration example become a reusable template?
- Did the skill add more process than the artifact deserved?

## Pass standard

A result passes only when required facts and actions survive and human review
finds no material voice, medium, authorship, or dignity failure. A pass is not a
claim that the writing is universally best; it means no costlier failure was
found in this case.

Record exact failures and the smallest general repair. Do not patch the skill
with phrases tailored to one eval.
